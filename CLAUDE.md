# Instructions for Claude in this repository

This repository is **generated**: it is a one-way export of `indigenica/whalefall` (folder list in
`paper/prd_network/export/MANIFEST.txt` there; source commit and file hashes in `EXPORT_PROVENANCE.json` here).

- **Do not edit files here.** Any change must be made in whalefall (`paper/prd_network/`, `network/`, …) and exported
  again with `make export-prd` from the whalefall root. A direct edit here is overwritten by the next export and is
  reported by `make check-prd` as "EDITADO EN DESTINO".
- To review or reproduce: `make test`, `make audit`, `make figures`, `make paper` (see `README.md`).
- The specifications and reports in `docs/` are the original dated records, in Spanish, and are never rewritten.
